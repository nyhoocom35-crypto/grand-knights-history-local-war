그란 나이츠 히스토리 — 로컬 전쟁 배포판 1.0.0
기반: v12.2 / 배포일: 2026-10-04

이 패키지는 종료된 온라인 전쟁을 대신하는 개인용 로컬 전쟁 모드입니다.
다른 사람도 각자 Windows PC에서 설치하여 독립된 전황으로 플레이할 수 있습니다.
여러 사람이 하나의 전황을 공유하는 온라인 멀티플레이 서버는 아닙니다.
게임 ISO, PPSSPP, 개인 세이브는 포함되어 있지 않습니다.

준비물
- Windows에서 powershell.exe로 실행되는 Windows PowerShell 5.1과 .NET Framework.
  Python이나 별도 C# 컴파일러 설치는 필요하지 않습니다.
- Windows용 PPSSPP와 본인이 준비한 한국어판 ULJS00394 ISO.
  이 제작에 사용한 한국어 게임 데이터와 정확히 일치하는 버전만 지원합니다.
  ULJS00394여도 다른 번역/수정판이면 패치 검증에서 거부될 수 있습니다.
- 해당 게임의 일반 저장 데이터. 새 플레이어는 먼저 원본 게임에서 저장을 만드세요.
- ISO가 있는 드라이브에 ISO 한 개를 추가로 복사할 수 있는 여유 공간.
- PPSSPP와 서버는 같은 PC에서 실행해야 합니다. 서버 주소는 127.0.0.1:80입니다.

처음 설치
1. ZIP을 통째로 압축 해제하세요. ZIP 안에서 바로 실행하지 마세요.
   모든 파일을 같은 폴더 구조로 유지하고, 쓰기 가능한 폴더를 사용하세요.
2. 게임을 일반 저장한 뒤 PPSSPP를 종료하세요.
3. START.bat 실행 → [1] 저장 백업.
   PPSSPP가 실제로 사용하는 PSP\SAVEDATA 폴더를 선택하세요.
   그 안에 ULJS00394로 시작하는 게임 저장 폴더가 있어야 합니다.
   예: 문서\PPSSPP\PSP\SAVEDATA 또는 PPSSPP\memstick\PSP\SAVEDATA.
   경로는 설치 방식에 따라 다르므로 실제 사용 중인 저장 위치를 확인하세요.
4. 메뉴 [2] ISO 패치 → 압축을 푼 .iso 파일을 선택하세요.
   원본 한국어 ISO 또는 이전 CONNECT_TEST.iso를 입력할 수 있습니다.
   옆에 *_CONTRACT_v12.iso가 생성됩니다. 원본 파일은 유지됩니다.
   EGG/ZIP/CSO를 직접 선택할 수 없습니다.
5. 메뉴 [3] 서버 실행. 별도 창에서 자체 테스트 PASS와
   Listening at http://127.0.0.1:80 표시를 확인하고 그 창을 켜 두세요.
6. PPSSPP에서 새 *_CONTRACT_v12.iso를 실행하고 기존 일반 저장을 불러오세요.
   게임의 네트워크/전쟁 접속 메뉴로 접속하여 전황을 동기화하세요.
7. 귀환한 상태에서 메뉴 [4] 국가 계약 창을 열어 국가와 전쟁 횟수를 선택하세요.
8. 계약 버튼을 누른 뒤 게임에서 재접속하여 소속국과 계약금 적용을 확인하세요.
9. 상점이나 전투를 진행하기 전에 한 번 더 재접속하세요.
   계약 창에 '지급 확인 완료'가 표시되면 게임도 일반 저장하세요.
10. 선택한 국가의 전장으로 출격하세요.

평소 실행
START.bat → [3] 서버 → PPSSPP에서 CONTRACT_v12.iso 실행 → 전쟁 접속.
서버는 한 번만 실행하세요. 게임 종료 뒤 서버 창에서 Ctrl+C로 종료할 수 있습니다.
런처나 계약 창만 닫아도 별도 서버 창은 계속 실행됩니다.
기존 CONTRACT_v12.iso는 이번 배포판에서도 그대로 사용하며 재패치할 필요 없습니다.

포함 기능
- 전쟁 종료 후 다음 전쟁/캠페인으로 자동 전환.
- 국가별 AI 투표 및 인접한 적 영토 중 최다 득표 목표 선택.
  수도는 침공 대상에서 제외. 수도와 연결된 자국 영토를 기준으로 국경을 검사.
  같은 목표가 겹치면 한 공격국을 결정하며, 유효한 목표가 없으면 해당 국가는 대기.
- 게임의 투표 표시와 서버 전황 파일에서 AI 득표 결과 확인.
- 플레이어가 참전하지 않아도 AI 점수에 따라 전황이 바뀜.
- 공격국 승리 시 영토 획득, 방어국 승리/동점 시 소유권 유지.
- 유니온/로그리스/아발론 계약, 기간 1~60회 선택, 계약금 선불 지급.
- 적 편성과 전장 진군 지점의 공격/방어 배치 및 경계 복원.
- 적 배치 조회는 기본적으로 1회 배치/2회 빈 배치로 순환하여 밀도 완화.

계약 규칙
강국 900G/회, 약국 1,100G/회, 중간 국가는 영토 수에 따라 그 사이 금액입니다.
모든 국가의 영토 수가 같으면 1,000G/회이며 수도도 영토 수에 포함합니다.
계약금은 확정 회당 금액 × 선택한 전쟁 횟수입니다.
견적은 현재 전황에 따라 바뀌며 서버가 계약을 접수할 때 금액을 확정합니다.
첫 적용 재접속부터 시작하고, 진행 중인 현재 전쟁도 1회에 포함합니다.
전쟁이 끝날 때마다 잔여 횟수가 줄고, 만료 뒤 다시 계약할 수 있습니다.
계약 중에는 국가 변경이나 추가 계약을 할 수 없습니다.
계약 만료 또는 계약국 불일치 시 새 적 부대를 제공하지 않습니다.
서버 재시작 시 지난 시간을 따라잡으므로 꺼 둔 기간에 계약이 만료될 수도 있습니다.
계약금 확인 전 소지금을 변경하지 마세요. 예상 잔액과 다르면 지급 검토 상태가 됩니다.
게임의 옛 저장/세이브스테이트만 복원하면 서버 계약 기록과 돈이 어긋날 수 있습니다.
복원할 때는 게임 저장과 서버 기록을 같은 시점의 백업으로 함께 복원하세요.

기존 v12.2 사용자 이전
1. 진군에서 귀환하고 게임 일반 저장 후 PPSSPP와 기존 서버를 종료하세요.
2. 기존 서버 폴더 전체를 보관한 뒤 새 배포 폴더로 아래 세 파일을 복사하세요.
   campaign_state.bin       전황·영토·투표·계약·지급 기록
   local-test-token.txt     로컬 계정 식별자
   unit-template-cache.bin  적 생성용 캐릭터 캐시
   local-war-state 폴더가 있다면 함께 옮겨 이전 회차 기록도 보존하세요.
3. 새 폴더에서 저장 백업 [1]을 다시 실행하세요.
   backup-info.json은 새 백업으로 생성됩니다. 새 설정 파일은 그대로 유지하세요.
4. 서버 [3] 실행 후 기존 CONTRACT_v12.iso로 재접속하세요.
   기존 계약은 유지되며 다시 계약하거나 ISO를 다시 만들 필요 없습니다.
   campaign_state.bin을 빼고 옮기면 새 전황이므로 반드시 복사하세요.
다른 사람에게 배포할 때는 이 개인 기록을 넣지 말고 최초 ZIP을 그대로 전달하세요.

지원 범위와 제한
- 계약 화면은 게임 내부가 아니라 별도 Windows 창입니다.
- 원래 온라인 서비스 전체를 복구한 패키지는 아닙니다.
  커뮤니티 등 미구현 요청은 오류가 나거나 HTTP503으로 기록될 수 있습니다.
- 플레이어 투표는 표시되지만 다음 전장 선정 합계에는 현재 AI 표만 반영됩니다.
- 적은 플레이어의 캐릭터 데이터를 바탕으로 생성하는 미러 부대입니다.
- 공유 계정, 원격 서버, 실제 다른 플레이어와의 대전은 지원하지 않습니다.
- 원본 PSP 실기나 다른 운영체제에서의 실행은 이 배포판 지원 범위에 없습니다.

문제 해결
자체 테스트 FAIL: 서버 창의 오류를 보관하고 누락/다른 버전 파일 혼합을 확인하세요.
Verified save backup missing: [1]에서 실제 저장 폴더를 다시 백업하세요.
80번 포트 오류: 같은 서버가 이미 켜져 있는지 확인하고 기존 창을 종료하세요.
게임 접속 실패: 서버 창, 같은 PC 사용, 패치한 CONTRACT_v12.iso 실행 여부 확인.
ISO 버전 오류: 정확한 한국어 원본/CONNECT_TEST 입력인지 확인하세요.
출력 ISO가 이미 있음: 기존 출력 파일을 따로 보관하거나 그것을 그대로 사용하세요.
계약 창에 정보 없음: 서버 실행 후 게임에서 먼저 한 번 접속하세요.
전투 지점/적 없음: 최신 전황 재접속, 계약 잔여 횟수/소속국/적 빈 배치 여부 확인.
해결되지 않으면 메뉴 [6]으로 진단 ZIP을 만들고 서버 오류와 게임 화면을 함께 전달하세요.
진단 ZIP에는 전황/계약 및 게임 요청 데이터가 있으므로 공개 배포물과 구분하세요.

파일 안내
번호 BAT 파일: 런처 없이도 각 기능을 직접 실행할 수 있습니다.
campaign_config.json: 전쟁 길이/AI 속도/적 밀도 설정. docs\CONFIG_KO.txt 참고.
docs\VERIFICATION_KO.txt: 검증 범위.
docs\PROTOCOL_HISTORY_KO.txt: 개발 과정의 기술 기록. 과거 설명은 현 버전 설명이 아닙니다.
SHA256SUMS.txt: 배포 파일별 무결성 확인용 SHA-256.
